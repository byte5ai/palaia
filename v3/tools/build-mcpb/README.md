# build-mcpb

SPEC-306's MCPB bundle: a thin stdio→hub proxy (`proxy/palaia-proxy.mjs`),
packaged with the official [`mcpb`](https://github.com/modelcontextprotocol/mcpb)
tooling.

- `proxy/palaia-proxy.mjs` — the proxy itself. Self-contained: only Node
  builtins, no `npm install` needed to *run* it (Claude Desktop ships a
  Node runtime). See its own docstring for the environment variables it
  reads and the wire protocol it speaks.
- `manifest.template.json` — the MCPB manifest, with `user_config`
  placeholders for the hub URL, token/OAuth issuer, and profile.
- `icon.png` — generated by `generate_icon.py` (no image library
  dependency; re-run it if the icon ever needs to change).
- `build.mjs` — stages the template, validates it, packs it, and signs it
  with the official `mcpb` CLI. `npm run build` (after `npm ci`) produces
  `dist/palaia.mcpb`. See `SIGNING.md` for exactly what that signature is
  worth.
- `test/proxy.test.mjs` — `node --test`, no network beyond a local fake
  HTTP server standing in for the hub. `npm test`.

`palaia_hub.mcpb` (the Python server package) reuses this directory
directly — the proxy script, the manifest template, the icon, and the
`mcpb` CLI it locates under `node_modules/.bin/` — to personalize and
re-sign one bundle per `/api/connect/mcpb` download. See that package's
docstring for how a packaged (non-editable) install locates this
directory.

## Local setup

```sh
npm ci        # installs @anthropic-ai/mcpb as a devDependency
npm test      # the proxy's own unit + local-integration tests
npm run build # dist/palaia.mcpb — validated, packed, self-signed
```

The real end-to-end proof (a real Node subprocess running this exact
script, driven by `fastmcp.Client` over real stdio, against a real hub
subprocess) lives in
[`v3/server/tests/e2e/test_mcpb_proxy.py`](../../server/tests/e2e/test_mcpb_proxy.py) —
run via `uv run pytest` from `v3/`, and skipped (not failed) when `node`
is not on `PATH`.
