Every AI tool you use starts each conversation from zero. Tell Claude about a
decision on Monday, and Codex has never heard of it on Tuesday. Explain a
house convention to one assistant, and the next one gets it wrong the same
way the first one did before you corrected it.

palaia is one memory that every AI tool you connect can read from and write
to. Save something once — a decision, a convention, a person, a project
detail — and every assistant you use afterward already knows it. It runs on
your own machine, as plain files you can open, read and back up like any
other document. Nothing about it depends on any one company staying in
business, and nothing leaves your machine unless you connect something that
reads it.

## What it actually does

- **Holds what your team or you already decided**, with the reason attached
  — not just "we use tabs" but "we use tabs because the formatter enforces
  it and mixed indentation broke a diff tool in March."
- **Lets an assistant look things up before it guesses.** A name it doesn't
  recognize, a convention it isn't sure of, a decision that might already be
  settled — it checks first instead of making something up.
- **Notices what's worth keeping while you work**, not only when you
  explicitly ask it to write something down. A well-set-up assistant saves a
  correction or a hard-won detail in the same turn you mention it.
- **Stays yours.** It's a folder of readable files on your machine, not a
  account you can be locked out of.

## How the pieces fit together

- A small program (the **hub**) runs on your machine, or a small server you
  control, and holds your memory.
- Every AI tool — Claude Code, Codex, claude.ai, ChatGPT, and others — connects
  to that same hub as one more tool it can use, the same way it might use a
  web search or a calculator.
- You can keep more than one memory (work and personal, say) and decide
  which tools see which one.
- A dashboard in your browser lets you look through what's been saved, invite
  a new AI tool in, and decide how far your memory reaches — just this
  device, or the internet too.
