# palaia 3.0.0-rc3 — third v3 release candidate

**The first build meant for a live test end to end.** Everything from [`3.0.0-rc2`](https://github.com/byte5ai/palaia/releases/tag/v3.3.0.0-rc2) is here; this note lists what changed since.

> [!IMPORTANT]
> **This is a release candidate, not a final release.** It has not yet had an external security review or a usability pass with fresh eyes. Run it, break it, tell us — and keep backups. **palaia v2 remains the stable, supported product** until 3.0.0 is final.

## Try it

```bash
docker run -d --name palaia-hub \
  -p 8420:8420 \
  -v palaia_home:/data \
  --restart unless-stopped \
  --security-opt no-new-privileges:true --cap-drop ALL \
  --read-only --tmpfs /tmp --tmpfs /run \
  ghcr.io/byte5ai/palaia-hub:beta
```

Then open `http://<host>:8420` (on many home networks also `http://palaia.local`) and follow the setup wizard. Other ways to install — Docker Compose, Synology, Raspberry Pi, a VPS with Tailscale, or the one-command installer for a server you already have — are in the [install guide](https://github.com/byte5ai/palaia/blob/main/v3/deploy/README.md).

This tag publishes the container image as `ghcr.io/byte5ai/palaia-hub:beta` and `ghcr.io/byte5ai/palaia-hub:v3.3.0.0-rc3` (amd64 + arm64), and attaches the Raspberry Pi appliance image to this release.

## New since rc2

**Memory & search**
- **Temporary memories for one task:** create one from the Explorer, copy the notes worth keeping into an everyday memory when you are done, then close it. Closing archives its folder; nothing is deleted.
- **`memory_status`** on every connection: an AI tool can check which memories it may read and write, how many notes they hold and how search works, instead of guessing that its memory is unavailable.
- **Is your AI tool actually using it?** The Clients page shows, per tool, how often it looked something up and saved something over the last seven days, and flags a tool that saves without looking anything up first.
- Saving a note that closely resembles an existing one names that note, so a tool can update it instead of keeping two versions.
- Notes that are recalled often rank a little higher; the boost fades when they stop being asked for.
- Home's activity list shows what changed before you opened the page.

**Backups**
- **Back up on a schedule**, and a **Backups** screen with each folder's last backup and a "Back up now" button.
- **Push a memory to a git repository** you own, such as a private GitHub repository. Only the notes go there, and the hub never overwrites commits it did not make.

**Telegram**
- The Telegram connector runs in the hub. The **Telegram** screen shows each bot's status and recent messages, and sets up bots, routing rules and send permissions without a restart.

**Installing**
- A one-command installer for an existing server, and a guided setup an AI assistant can walk you through.
- The unattended cloud setup file pins the `:beta` image during the release candidates.

**Marketplace**
- Only add-ons that can actually be installed are offered, and each server from the official MCP registry is listed once.

**Fixes**
- The image now contains `git` (creating a memory failed without it) and the embedding backend (search combines keywords and meaning).
- Embeddings kept working when the default model's files changed upstream on 2026-09-27.
- The running hub picks up tokens created or revoked on the command line; a revoked token used to keep working until a restart.
- Redirects and the Claude Desktop bundle's address keep the published port.

The full list is in the [changelog](https://github.com/byte5ai/palaia/blob/main/v3/CHANGELOG.md).
