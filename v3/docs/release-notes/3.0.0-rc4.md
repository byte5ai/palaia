# palaia 3.0.0-rc4 — fourth v3 release candidate

**A small step on top of rc3.** Everything from [`3.0.0-rc3`](https://github.com/byte5ai/palaia/releases/tag/v3.3.0.0-rc3) is here; this note lists what changed since.

> [!IMPORTANT]
> **This is a release candidate, not a final release.** Run it, break it, tell us — and keep backups.

## Try it

```bash
docker run -d --name palaia-hub \
  -p 8420:8420 \
  -v palaia_home:/data \
  --restart unless-stopped \
  --security-opt no-new-privileges:true --cap-drop ALL \
  --read-only --tmpfs /tmp --tmpfs /run \
  ghcr.io/byte5ai/palaia-hub:beta
```

Then open `http://<host>:8420` (on many home networks also `http://palaia.local`) and follow the setup wizard. Other ways to install — Docker Compose, Synology, Raspberry Pi, a VPS with Tailscale, or the one-command installer for a server you already have — are in the [install guide](https://github.com/byte5ai/palaia/blob/main/v3/deploy/README.md).

This tag publishes the container image as `ghcr.io/byte5ai/palaia-hub:beta` and `ghcr.io/byte5ai/palaia-hub:v3.3.0.0-rc4` (amd64 + arm64), and attaches the Raspberry Pi appliance image to this release.

## New since rc3

**Memory & search**
- **A heads-up when a note has a known problem.** The hub checks your memory once each time it starts. When an AI tool then reads a note that links to a renamed note by its old name, shares its address with another note, or cannot be edited because of its text encoding, the answer says so and names the next step — fix the link on line N, or put the change in a new note. The hint is checked against your memory as it is now before it is shown, so a link that was repaired since is not mentioned.

**Documentation**
- palaia v2 is described as retired everywhere: no new features, only critical fixes, v3 replaces it. The [migration guide](https://github.com/byte5ai/palaia/blob/main/v3/docs/migrate-from-v2.md) brings your v2 knowledge over.
- Private vulnerability reporting is switched on — the channel [`SECURITY.md`](https://github.com/byte5ai/palaia/blob/main/v3/SECURITY.md) names.
- The Telegram connector has its own page on the docs site, and the feature overview covers what rc3 added.

The full list is in the [changelog](https://github.com/byte5ai/palaia/blob/main/v3/CHANGELOG.md).
