# palaia 3.0.0-rc11 — eleventh v3 release candidate

**The dashboard in a new, denser design with a command palette, and a setup guide that does more of the install itself.** Everything from [`3.0.0-rc10`](https://github.com/byte5ai/palaia/releases/tag/v3.3.0.0-rc10) is here; this note lists what changed since.

> [!IMPORTANT]
> **This is a release candidate, not a final release.** Run it, break it, tell us — and keep backups.

## Try it

On a Linux server (tested on Ubuntu 24.04):

```bash
curl -fsSL https://get.palaia.ai | sh
```

The installer sets up Docker and Tailscale if they are missing and prints the address of a one-time setup page and its code. Open the page in your browser, enter the code and log in to Tailscale; the page then offers cloud access for ChatGPT and Claude. When it prints `done ✓`, open the address it shows — usually `http://palaia/` — and palaia's setup takes you to a working AI connection.

Already running Docker on a Linux machine at home? The container on its own:

```bash
docker run -d --name palaia \
  --network host -e PALAIA_CLOUD_BIND=127.0.0.1 \
  -v palaia_home:/data \
  --restart unless-stopped \
  --security-opt no-new-privileges:true --cap-drop ALL \
  --read-only --tmpfs /tmp --tmpfs /run \
  ghcr.io/byte5ai/palaia:beta
```

Then open `http://palaia.local:8420/` from another device on the same network. Docker Desktop (macOS, Windows), Docker Compose, Synology, Raspberry Pi and a VPS created with the server-creation file are in the [install guide](https://github.com/byte5ai/palaia/blob/main/v3/deploy/README.md).

This tag publishes the container image as `ghcr.io/byte5ai/palaia:beta` and `ghcr.io/byte5ai/palaia:v3.3.0.0-rc11` (amd64 + arm64), and attaches the Raspberry Pi appliance image to this release.

## New since rc10

**Dashboard**
- **Search and jump from the keyboard.** Ctrl+K (⌘K on a Mac) or `/` opens a command palette on every page: reach any page or Settings area, connect an AI app, switch the appearance, or find a note in any of your memories. The sidebar has a search field for it, the phone's top bar a search button (#680).
- **A denser, calmer look.** Inter replaces Nunito Sans on the dashboard, setup, the installer's setup page, the sign-in page, the docs and the panels inside a chat. Text is 14 px, controls are 36 px high (44 px on a phone), buttons have 8 px corners (#642).
- **AI apps is a table**, with a panel on the right for connecting one app. Tool sets, live sessions and the memory-use list are tables as well (#642, #672).
- **Settings has its own navigation** beside the open area: General, Access & sign-in, Backups, Telegram, Advanced, About & updates (#642).
- **The activity feed and a note's history say which AI app saved it** (#677).
- **One click to add palaia to the Claude app**: with cloud access on, **Add to Claude** opens Claude's connector dialog with the name and palaia's public address filled in.

**Setup with an AI assistant**
- **The assistant runs the server part itself** when the chat app can run commands on your computer: the Claude app's Code tab or Codex in the ChatGPT app. The provider's web console stays the fallback (#653).
- **The assistant opens the setup pages itself** when it can work a browser on your computer, and fills in what is not secret. It stops at every sign-in and password (#654).
- **The guide asks for the Tailscale account first**, so the setup page's 30 minutes are not spent signing up (#650).

**Install**
- **The install goes on when the session that started it ends.** It runs on the server on its own and writes its progress to `/var/log/palaia-install.log`; running the command again shows that progress (#646).
- **A failed join to the private network says why**, in Tailscale's own words and with the likely cause (#647).
- **A missed setup page is one server restart away** on a server made with the setup file (#650).
- **Cloud access can be turned on without a terminal on the server** (#649).

**Fixed**
- An empty memory no longer shows "1 note" (#642).
- A captured note reads as text and facts, not as internal markers (#677).
- Checkboxes, radio buttons and switches take a 44 px tap on a phone; field and button edges reach a contrast of 3:1 (#642).
- The setup guide says which ChatGPT plans can save notes (#648), and every place it sends you to exists for this release (#651).

The full list is in the [changelog](https://github.com/byte5ai/palaia/blob/main/v3/CHANGELOG.md).

## Known gaps

- An AI app that signs in with the owner's account instead of an access key appears in the activity feed without its name.
- The new look reaches the docs at palaia.byte5.ai/docs with the site's next update.
- Unchanged from rc8: the Raspberry Pi redirect was checked on an x86 test machine with the same units, not on Pi hardware; Synology's Container Manager with the host network was not checked.
- Unchanged from rc8: the ChatGPT and Claude apps themselves, Tailscale's own service and Funnel, Claude Desktop installing the extension, and the server-creation file on a real cloud provider were not part of the checks; the test network ran a self-hosted control server (Headscale).
- [`v3/RELEASING.md`](https://github.com/byte5ai/palaia/blob/main/v3/RELEASING.md) lists what still stands between this RC and 3.0.0.
