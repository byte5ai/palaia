---
title: E1 Checkbox Charset
permalink: notes/e1-checkbox-charset
---

- [>] forwarded task marker
- [~] cancelled task marker
- [?] question task marker
- [!] flagged task marker
- [i] info task marker
- [I] info-caps task marker
- [X] done-caps task marker
- [-] single-hyphen task marker
- [xx] not a checkbox, this is a real category
