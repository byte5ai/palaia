# palaia

Shared memory for every AI assistant you use.

palaia gives every AI assistant on your devices — Claude, ChatGPT, Codex,
and more — access to the same notes. Write something down once from any
of them and the others can bring it back up later.

Everything runs on your own Runtipi server. Nothing leaves your network
unless you turn on remote access yourself, and doing that is a guided,
opt-in step, never the default.

Getting started takes one setup wizard in the browser — no command line.
